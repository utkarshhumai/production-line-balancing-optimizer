# production-line-balancing-optimizer
Production line balancing and capacity optimization using Python, RPW and Streamlit.
**Production Line Balancing & Capacity Optimization System | Python, Streamlit, Pandas, Matplotlib**

- **Problem:** Analyzed a simulated 15-task manufacturing line with precedence constraints to identify workstation bottlenecks, workload imbalance, and idle time under varying production demand.
- **Development:** Developed a Python-based Ranked Positional Weight (RPW) algorithm and interactive Streamlit dashboard to allocate tasks, visualize workstation workloads and task precedence, and calculate cycle time, line efficiency, utilization, and idle time.
- **Results:** Evaluated production scenarios of 350, 400, and 450 units/day; achieved 84.76% line efficiency with 7 workstations at 400 units/day and generated downloadable CSV reports for workstation allocation and performance analysis.
